   cheap-tier entry `opencode/gemini-3.5-flash`.

### OpenRouter model-id gotcha (matters for §4 "first slash only" parsing)
`--provider openrouter --model anthropic/claude-opus-4-8` (HYPHENATED) works and bills.
The ids as listed in models-store.json are DOTTED (`anthropic/claude-opus-4.8`,
`anthropic/claude-opus-5`) and both 404 through this gateway. The hyphenated form emits
`Warning: Model "..." not found for provider "openrouter". Using custom model id.` on
stderr but is passed through and served correctly; `message.model` echoes back exactly
what was sent, so there is no silent substitution. Do NOT "fix" the persona frontmatter
to the dotted store ids - that breaks it. The §4 first-slash-only split rule is unaffected
and correct: openrouter/anthropic/claude-opus-4-8 -> provider=openrouter,
model=anthropic/claude-opus-4-8.

### Stream-shape findings that change the runner implementation
- `message_end` fires for NON-assistant messages too. Observed roles in the tool probe:
  ["user","toolResult","toolResult"] alongside 3 assistant messages. §7.1 says "fires for
  every assistant message", which is true but incomplete. runner/direct.ts MUST filter
  `message.role === "assistant"` before summing usage, or it will iterate messages that
  have `usage: undefined` and (if summing naively) count phantom entries in messageCount.
- The §7.1 accounting rule is empirically CONFIRMED and material: summed cost 0.029696 vs
  last-message-only 0.012622 = 2.35x undercount on a 2-tool-call turn (attempt 1 measured
  5.69x on the same probe shape). A 6-tool-call Skeptic turn will undercount far worse.
- Assistant content block types per message: [["toolCall"],["toolCall"],["text"]]. Only the
  FINAL assistant message carried text; intermediate ones were pure toolCall. Confirms
  "text = final message_end, text blocks only, skip thinking/toolCall".
- `cacheRead` was already 2176 tokens WITHIN a single tool-using turn (the agentic loop
  re-sends the prefix and the provider caches it). So §13 item 8 is partly answered
  already: caching engages intra-turn on openai-codex. Cross-turn caching still to be
  measured in WP4.
- `--` and `@path` both behave exactly as §6.2 states: the attached file's content reached
  the model (it quoted MARKER-LINE-7f3a verbatim) without appearing in argv as text.
- `--tools read,grep,find,ls,bash` genuinely grants bash: tool_execution_start fired with
  toolName "bash". The silent-drop risk in §7.3 did not materialize.
